# Introduction to Linux

Canonical reusable Linux learning material for RCET courses.

This repository is a shared public resource. Individual courses decide when and how much of it to use; course-specific assignments, schedules, submission rules, and grading remain in the owning course.

## Lessons

1. [`lesson-01-intro.md`](lesson-01-intro.md) - introduction and orientation
2. [`lesson-02-desktop.md`](lesson-02-desktop.md) - desktop environment
3. [`lesson-03-cli.md`](lesson-03-cli.md) - command-line basics
4. [`lesson-04-files.md`](lesson-04-files.md) - files and filesystem work
5. [`lesson-05-editing.md`](lesson-05-editing.md) - text editing
6. [`lesson-06-processes.md`](lesson-06-processes.md) - processes
7. [`lesson-07-packages.md`](lesson-07-packages.md) - software/package management
8. [`lesson-08-final.md`](lesson-08-final.md) - final/integration material
