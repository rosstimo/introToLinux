# Session 1: Introduction to Linux and Operating Systems

**Duration:** 50 minutes  
**Target Audience:** Absolute beginners  
**Prerequisites:** None

## Learning Objectives

By the end of this session, students will be able to:
- Understand what Linux is and its historical development
- Identify different Linux distributions and their purposes
- Compare Linux with other operating systems (Windows, macOS)
- Understand fundamental concepts: kernel, shell, and filesystem

## Materials Needed
- Computer with internet access
- Virtual machine software (VirtualBox, VMware) or USB drive
- Linux distribution ISO file (Ubuntu recommended for beginners)
- Projector/screen for demonstrations

## Session Outline

### Opening (5 minutes)
- Welcome and introductions
- Course overview and expectations
- Safety guidelines for system installations

### Part 1: What is Linux? (10 minutes)
**Content:**
- Definition: Unix-like, open-source operating system
- History: Created by Linus Torvalds in 1991
- Philosophy: Free and open-source software (FOSS)
- Community-driven development model
- License: GNU General Public License (GPL)

**Key Points:**
- Linux is the kernel, not the complete operating system
- GNU/Linux is the full operating system
- Difference between free (freedom) and free (cost)

### Part 2: Linux Distributions (15 minutes)
**Content:**
- What is a distribution (distro)?
- Popular distributions:
  - **Ubuntu**: Beginner-friendly, large community
  - **Fedora**: Cutting-edge features, sponsored by Red Hat
  - **CentOS/RHEL**: Enterprise-focused, stable
  - **Debian**: Stable, foundation for many other distros
  - **Arch Linux**: Advanced users, rolling release
  - **Linux Mint**: User-friendly, based on Ubuntu

**Selection Criteria:**
- Purpose (desktop, server, development)
- Support and community
- Package management system
- Release cycle (fixed vs rolling)

### Part 3: Operating System Comparison (10 minutes)
**Linux vs. Windows vs. macOS:**

| Aspect | Linux | Windows | macOS |
|--------|-------|---------|--------|
| Cost | Free | Paid | Paid (with hardware) |
| Source Code | Open | Closed | Closed |
| Customization | High | Medium | Low |
| Hardware Support | Good | Excellent | Limited |
| Software Availability | Good | Excellent | Good |
| Security | Excellent | Good | Excellent |
| Learning Curve | Steep | Gentle | Medium |

### Part 4: System Architecture (10 minutes)
**Key Components:**
1. **Kernel**: Core of the operating system
   - Hardware management
   - Process scheduling
   - Memory management
   - Device drivers

2. **Shell**: Command-line interface
   - User interaction with kernel
   - Command interpretation
   - Script execution

3. **Filesystem**: File organization structure
   - Hierarchical directory structure
   - File permissions and ownership
   - Mount points for devices

## Activities

### Activity 1: Linux Distribution Research (15 minutes)
**Group Activity:**
- Divide class into groups of 3-4 students
- Assign each group a Linux distribution
- Research and present:
  - Target audience
  - Key features
  - Package manager used
  - Desktop environment options

### Activity 2: Linux Installation (20 minutes)
**Hands-on Practice:**
- Guide students through Ubuntu installation in VirtualBox
- Key steps:
  1. Download Ubuntu ISO
  2. Create new virtual machine
  3. Configure VM settings (RAM, storage)
  4. Boot from ISO
  5. Follow installation wizard
  6. Basic system configuration

**Alternative:** Create live USB for students without virtualization capability

### Activity 3: First Login and Desktop Exploration (5 minutes)
- Boot into installed system
- Explore desktop environment
- Identify key elements:
  - Desktop background
  - Panel/taskbar
  - Application menu
  - File manager icon
  - System settings

## Assessment Questions

### Quick Check (5 minutes)
1. What does "open source" mean?
2. Name three popular Linux distributions
3. What are the three main components of a Linux system?
4. How is Linux different from Windows in terms of cost?

## Homework Assignment
- Complete the installation if not finished in class
- Explore the desktop environment for 15 minutes
- Find and open the following applications:
  - Web browser
  - Text editor
  - File manager
  - Terminal (don't use it yet!)

## Troubleshooting Guide

### Common Installation Issues:
- **Virtualization not enabled**: Check BIOS settings
- **Insufficient RAM**: Allocate at least 2GB to VM
- **Storage space**: Ensure at least 20GB available
- **ISO corruption**: Re-download distribution file

### Resources for Students:
- Ubuntu documentation: https://help.ubuntu.com
- VirtualBox user manual
- Linux community forums
