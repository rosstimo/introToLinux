| Resource                                                            | What It Covers / Good For                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Linux Foundation – “Introduction to Linux (LFS-101)”**            | A very well-structured beginner course: covers Linux basics, system startup, GUI + CLI, system config, file management, permissions, and user/admin tasks. Great as a starting point for students with little or no Linux experience. ([Linux Foundation - Education][1]) |
| **LinuxCommand.org**                                                | A straightforward, no-frills site focused on learning the shell: basic commands, scripting, etc. Good reference for students messing around in the terminal. ([linuxcommand.org][2])                                                                                      |
| **Ubuntu – “The Linux Command Line for Beginners” tutorial**        | Gentle intro to command line basics: navigating directories, file manipulation, understanding CLI concepts. Useful for students new to terminal-based workflows. ([Ubuntu][3])                                                                                            |
| **Linux Survival**                                                  | Interactive web-tutorial with a simulated terminal. Students can practice basic commands without installing Linux locally. Nice sandbox for first exposure. ([linuxsurvival.com][4])                                                                                      |
| **Ryan's Tutorials – Linux Tutorial for Beginners**                 | A step-by-step 13-part guide focusing on Bash, essential commands, and practical examples — simple enough for novices. ([ryanstutorials.net][5])                                                                                                                          |
| **GeeksforGeeks – Linux/Unix Tutorial**                             | Covers a broad range: from distro basics to filesystems, command usage, package management, user & permission handling, scripting, networking — good for building toward admin/ops tasks. ([GeeksforGeeks][6])                                                            |
| **Codecademy – “Introduction to Linux” & “Learn The Command Line”** | Interactive course options that teach shell, filesystem navigation, commands, permissions, environment setup. Useful for students who benefit from guided, interactive learning. ([Codecademy][7])                                                                        |
